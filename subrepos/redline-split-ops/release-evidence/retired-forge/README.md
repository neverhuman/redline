# Retired control-plane evidence

These immutable files describe the former split-repository deployment. They are
historical evidence, never configuration or release authority. Their original
bytes and identities are retained in `custody.json`; the old executable source
is recoverable from the recorded GitHub commit.

Active source, validation and releases use [neverhuman/RedlineDB](https://github.com/neverhuman/RedlineDB),
root `subrepos.toml`, root workflows, and the included component workspaces.
